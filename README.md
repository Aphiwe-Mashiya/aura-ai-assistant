# Aura AI Assistant

Create a modern responsive frontend-only SaaS app called “AI Workplace Productivity Assistant.” Do not use a backend, database, authentication, or external API. Use realistic, personalized local AI-style responses rather than generic placeholder text.

Use a clean professional design with pink, white, and light blue colors, a modern dashboard, rounded cards, subtle shadows, clear typography, and responsive desktop/mobile layouts.

Include:

- Sidebar navigation: Dashboard, Email Generator, Meeting Summarizer, Task Planner, and Settings.
- Dashboard with welcome message, productivity statistics, recent activity, and quick actions.
- Smart Email Generator with recipient, subject, purpose, and key-points fields; Formal, Friendly, and Persuasive tone options; and editable generated email results with Copy and Clear buttons.
- Meeting Notes Summarizer with a notes input area and editable output sections for Summary, Action Items, Decisions, and Deadlines.
- AI Task Planner for creating daily or weekly schedules, prioritizing tasks by urgency and importance, and displaying tasks in an editable timeline or task board.
- Add loading states, empty states, toast notifications, localStorage, and polished icons.
- Include a visible disclaimer: “AI-generated content may require review. Verify important information before use.”

Keep the interface polished, simple, and professional, similar to a modern productivity SaaS platform.
