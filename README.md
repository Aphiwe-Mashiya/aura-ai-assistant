# AI Workplace Productivity Assistant
## Project Overview
The **AI Workplace Productivity Assistant** is a modern, responsive web application designed to help professionals automate everyday workplace tasks using Artificial Intelligence.
This project was built as part of the CAPACITI AI-Powered Productivity Project. It is a **single, integrated application** with multiple AI features in one dashboard, not multiple separate apps.
The goal is to save time, improve communication, and help users stay organized at work.
> **Live Demo:** https://prompt-palace-800.lovable.app/
> **Repository:** AI-Productivity-Assistant
##  Features Implemented
### 1. Smart Email Generator
- Generates professional emails from a simple prompt.
- Supports multiple tones: **Formal, Friendly, and Persuasive**.
- Input: What the email should cover.
- Output: Subject line + full professional email.
- Includes options for Length (Concise, Detailed) and Audience (Client, Internal).
### 2. Meeting Notes Summarizer
- Summarizes lengthy meeting transcripts or notes.
- Automatically extracts:
   - **Summary - Quick Overview**
   - **Action Items** with assignees and due dates
   - **Decisions Made**
   - **Deadlines**
- Output is editable and exportable to tasks.
### 3. AI Task Planner
- Generates daily or weekly schedules from a list of tasks.
- Prioritizes tasks effectively based on urgency and importance.
- Helps users plan their workday more efficiently.
### Core UI Features
- Modern Dashboard Layout
- Sidebar Navigation
- Fully Responsive Design (Desktop and Mobile)
- Structured Input and Output sections
- Editable AI outputs with Copy, Regenerate, and Export
- Professional UI/UX - Clean SaaS design with pink, white, and light blue theme
- Responsible AI Disclaimer: "AI can make mistakes, please verify"
##  Responsible AI
- Includes a responsible AI disclaimer.
- Reminds users to review AI-generated information before using it professionally.
- Designed to support users rather than replace professional judgement.
